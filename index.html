LM Studio Local Setup Guide

                    100% Offline AI Configuration for Windows 11
                

                
            

            

                

                    
1

                    

                        
Download & Open LM Studio

                        
Launch LM Studio on your Windows 11 machine.

                    

                


                

                    
2

                    

                        
Download a Compatible Model

                        
Search and download any instruction or coding model in GGUF format.

                    

                


                

                    
3

                    

                        
Start the Local Server

                        
Click on the Local Server (<-> icon) tab in LM Studio, select your model, and click "Start Server" on port 1234.

                    

                


                

                    Hackathon Tip: Once your model is downloaded and running on port 1234, you can completely disconnect Wi-Fi. EasyMind AI will continue to generate code, run Python and JavaScript, execute SQL queries, and diagnose bugs 100% offline!
